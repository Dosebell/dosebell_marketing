# DoseBell marketing site

Static HTML, CSS, and JavaScript. No build step or analytics.

Preview: `python3 -m http.server 8000` from this directory.

The homepage links to the support mailbox for release information until a verified App Store or TestFlight URL is supplied. Replace availability calls to action and add the real App Store smart banner only when that URL exists. No fabricated reviews or ratings are included.

The interactive preview uses illustrative medication names and does not store personal information. Support and privacy copy describe the implemented permissions and sharing behavior.
